# US Stock Market Analysis using SQL

## Overview

This project analyzes historical stock market data of major US companies using SQL. The analysis focuses on stock prices, trading activity, daily returns, and company-wise performance.

## Companies Analyzed

- Apple (AAPL)
- Microsoft (MSFT)
- NVIDIA (NVDA)
- Amazon (AMZN)
- Alphabet (GOOGL)
- Meta (META)
- JPMorgan Chase (JPM)
- Visa (V)
- Walmart (WMT)
- Tesla (TSLA)

## SQL Concepts Used

- SELECT and WHERE
- GROUP BY and aggregate functions
- ORDER BY
- JOIN
- Common Table Expressions (CTEs)
- Window Functions
- LAG()
- Date-based analysis
- Return calculation

## Key Analysis

The project includes 12 SQL queries covering:

- Stock price analysis
- Company-wise comparisons
- Trading activity
- Historical trends
- Daily return calculation
- Average daily returns
- Performance comparison between companies

## Files

- `stock_analysis.sql` — SQL queries used for the analysis
- `stock_data.csv` — Historical stock market dataset
